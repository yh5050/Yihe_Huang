# Yihe Huang — Portfolio

Interactive 3D portfolio (Three.js) of Yihe Huang: UX Research, Art, Media, Publication, and About & Contact.

- `index.html` — the page (template + app logic)
- `runtime.js` — small renderer that drives the template
- `three.min.js` — Three.js r149
- `assets/` — images and videos

## Run locally
Open a terminal in this folder and run `python3 -m http.server`, then visit http://localhost:8000.

## GitHub Pages
Settings → Pages → Source: "Deploy from a branch" → Branch: `main`, folder `/ (root)`.
